## ✦ Proje hakkında

**Dynamic Island Win**, macOS/iOS tarafında tanınan Dinamik Ada fikrini Windows masaüstüne uyarlayan bir WPF uygulamasıdır. Medya denetimlerini, zamanlayıcıyı, hava durumunu ve sık kullanılan araçları küçük, genişletilebilir bir alanda bir araya getirir.

Arayüz; akıcı geçişler, kişiselleştirilebilir temalar ve masaüstü kullanımına uygun etkileşimler üzerine kuruludur.

## 📦 Kurulum

### Hazır sürüm

1. [**Releases**](https://github.com/cesurefe6355/Dynamic-Island-Win/releases/latest) sayfasını açın.
2. Yayımlanmış en son sürümün arşivini indirin ve bir klasöre çıkarın.
3. `Dynamic_Island_Win.exe` dosyasını çalıştırın.

### Kaynak koddan çalıştırma

Gereksinimler: **Windows 10/11** ve **.NET 8 SDK**.

```powershell
git clone https://github.com/cesurefe6355/Dynamic-Island-Win.git
cd Dynamic-Island-Win
dotnet restore
dotnet build -c Release
dotnet run
```

## ⌨️ Klavye kısayolları

| Kısayol | İşlev |
|:--|:--|
| `Ctrl` + `Shift` + `H` | Dinamik Ada'yı gösterir veya gizler. |
| `Esc` | Açık pencere veya ayar görünümünü kapatır. |
| `Space` | Ada odaktayken medyayı oynatır/duraklatır. |
| `←` / `→` | Ada odaktayken önceki/sonraki parçaya geçer. |

## 🎨 Temalar
